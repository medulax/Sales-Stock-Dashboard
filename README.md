# sales-stock-dashboard
A Flutter-based business management application designed for retail stores and multi-store businesses, providing real-time access to sales, inventory, cash management, and banking information through a centralized dashboard.

## Features
- Sales tracking and reporting
- Inventory management
- Cash and bank account monitoring
- Multi-branch support
- REST API integration
- Real-time business dashboard

## Technologies
- Flutter
- Dart
- Node.js
- REST API
- SQL Server

## Note
Sensitive company data, credentials, and configuration files have been removed for security and privacy reasons.
